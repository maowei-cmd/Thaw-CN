Thaw-CN（非官方简体中文版）安装说明

1. 退出正在运行的官方 Thaw。
2. 把 Thaw.app 拖到“应用程序”文件夹。
3. 首次启动如果提示“无法验证开发者”，打开“系统设置 → 隐私与安全性”，
   在“安全性”中点击“仍要打开”。
4. 按提示授予辅助功能、菜单栏布局访问权限；屏幕录制为可选项。

注意：
- 本构建使用与官方 Thaw 相同的 Bundle ID，不能与官方版同时安装。
  建议安装前备份偏好：
  defaults export com.stonerl.Thaw ~/Desktop/thaw-backup.plist
- 本构建为 ad-hoc 签名，未经过 Apple 公证。
- 自动更新已关闭，升级请重新下载新版本。
- 本版本基于 thaw-app/Thaw（GPL-3.0），不是官方版本。
- macOS 27 不会把微信、输入法菜单、万年历绘制到副屏菜单栏；
  本版会在该屏的 Thaw 工具栏中提供访问入口。
